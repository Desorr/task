# Тестовое задание

## Описание

Реализация асинхронной функции `recommend_price()` для автоматического расчёта рекомендованной цены товара на основе предложений конкурентов.

Функция учитывает стоимость товара, сроки доставки, минимально допустимую цену и отклонение от текущей цены.

## Логика работы

1. Получение предложений конкурентов с ограничением времени ожидания — 2 секунды по умолчанию.
2. Обработка исключений, тайм-аутов и некорректного статуса источника.
3. Фильтрация предложений:
   - исключается собственный магазин `MYSHOP` (без учёта регистра);
   - учитываются только предложения с известным сроком доставки до 6 дней включительно.
4. Выбор минимальной цены среди подходящих предложений.
5. Снижение минимальной цены конкурента на 1,5% с округлением вниз до копейки.
6. Применение ограничения `min_price`.
7. Проверка отклонения от текущей цены:
   - `APPLY` — рекомендация может быть применена автоматически;
   - `REVIEW` — требуется ручная проверка, если отклонение превышает 30%;
   - `HOLD` — сохранение текущей цены, если источник вернул ошибку, произошёл тайм-аут или отсутствуют подходящие предложения.

## Автоматические тесты

Реализованы два тестовых сценария:

1. **Успешный расчёт цены** — проверка фильтрации предложений конкурентов, расчёта скидки, округления и результата `APPLY`.
2. **Тайм-аут источника** — проверка ограничения времени ожидания и возврата текущей цены с решением `HOLD`.

Ожидаемый результат:

```text
test_starter.py::test_recommend_price_success PASSED
test_starter.py::test_recommend_price_timeout PASSED

======================== 2 passed ========================
```

## Результат

Функция возвращает словарь с тремя полями:

- `price` — рекомендованная цена типа `Decimal`;
- `decision` — принятое решение (`APPLY`, `REVIEW` или `HOLD`);
- `reason` — краткое описание причины принятого решения.
